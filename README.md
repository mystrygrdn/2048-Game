## 📖 About This Project

This **2048 Game** is a web-based implementation of the famous sliding tile puzzle. The main focus of this project was to practice **Array Manipulation** and **DOM Manipulation** using Vanilla JavaScript. 

Players slide numbered tiles on a grid to combine them to create a tile with the number 2048. The game includes a real-time scoring system and a "Game Over" modal to provide a complete user experience.

---

## ✨ Features

### 🕹️ Core Gameplay
- **Smooth Grid Movement:** Logic for sliding tiles in four directions (Up, Down, Left, Right).
- **Tile Merging:** Tiles with the same number merge into one when they touch.
- **Random Spawn:** New tiles (2 or 4) spawn after every valid move.

### 📊 Feedback & UI
- **Real-time Scoring:** Track your progress as you combine tiles.
- **Game Over Modal:** A stylish pop-up that appears when no more moves are possible, showing your final score.
- **Restart Functionality:** Quick reset button to start a new game instantly.

### 🎨 Visuals
- **Responsive Layout:** Centered card design that works well on various screen sizes.
- **CSS Transitions:** Smooth animations for tile movements and merges.
